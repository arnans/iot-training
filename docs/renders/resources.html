รวมไฟล์และลิงก์

หน้านี้รวมทุกไฟล์และทุกลิงก์ที่ผู้เข้าอบรมต้องใช้ไว้ที่เดียว เปิดหน้านี้เมื่อจำไม่ได้ว่าของที่ต้องการอยู่หน้าไหน ขั้นตอนการทำงานจริงอยู่ในใบงานแต่ละช่วง

1. ก่อนวันอบรม — ติดตั้งลงแล็ปท็อป

ทำให้เสร็จและส่งแบบยืนยัน อย่างน้อย 3 วันก่อนวันอบรม ขั้นตอนละเอียดพร้อมภาพประกอบอยู่ในคู่มือเตรียมแล็ปท็อป

ดูว่าแล็ปท็อปของเราเป็นแบบไหน แล้วดาวน์โหลด ทั้งสองไฟล์ในแถวนั้น (Mac: เมนู Apple → About This Mac ดูบรรทัด Chip หรือ Processor)

แล็ปท็อป VirtualBox ไฟล์ Farm Workshop (TODO GB)
Windows Windows hosts farm-workshop-x86-64.ova
Mac ชิป Intel macOS / Intel hosts farm-workshop-x86-64.ova
Mac ชิป Apple (M1 ขึ้นไป) macOS / Apple Silicon hosts farm-workshop-arm64.ova

ไฟล์ .ova มีขนาดใหญ่ ดาวน์โหลดที่บ้านหรือที่ทำงานล่วงหน้า ดาวน์โหลดที่สถานที่อบรมไม่ทัน · ต้องมี RAM 8 GB และพื้นที่ว่าง 20 GB ขึ้นไป · Chromebook, iPad และ Windows ชิป ARM ใช้ไม่ได้

สิ่งที่ต้องทำ ลิงก์
คู่มือติดตั้งทีละขั้น เตรียมแล็ปท็อปก่อนการอบรม
ส่งภาพหน้าจอยืนยันว่าติดตั้งสำเร็จ แบบยืนยันการติดตั้ง
ติดปัญหาระหว่างติดตั้ง ติดต่อทีมผู้สอน: TODO (ช่องทางติดต่อ และเวลาช่วงช่วยเหลือออนไลน์)
ไฟล์ที่ต้องมีหากติดตั้ง VirtualBox บน Windows แล้วไม่ผ่าน vc_redist.x64.exe

2. ใบงานที่ใช้ระหว่างอบรม

เปิดจากโทรศัพท์หรือแล็ปท็อปก็ได้ คำตอบที่กรอกจะถูกจำไว้ในเบราว์เซอร์ของเครื่องที่กรอก

หน้า ใช้เมื่อ
เริ่มต้นที่นี่ ดูภาพรวม อุปกรณ์ในชุด ข้อควรระวัง และคำศัพท์
ช่วงที่ 1 — รับรู้ ตัดสินใจ สั่งการ อ่านค่าเซนเซอร์ ต่อวงจร 12V และสั่งปั๊มจากแดชบอร์ด
ช่วงที่ 2 — ควบคุมอัตโนมัติและ Fail-safe เขียนกฎอัตโนมัติ hysteresis และกฎกันพลาด
ช่วงที่ 3 — แดชบอร์ดและออกแบบระบบ อ่านกราฟ สร้างแดชบอร์ด และทำแบบร่างระบบของทีม
ใบบันทึกของทีม รวมคำตอบทุกช่อง + แบบร่างระบบ กด ดาวน์โหลดคำตอบ ก่อนจบการอบรม และ พิมพ์ / บันทึก PDF ไว้อ้างอิง
เมนูและวิธีแก้ปัญหา ค้นเมนู Home Assistant และแก้อาการที่เจอบ่อย

ทีมที่สะดวกเขียนกระดาษ ให้พิมพ์ใบบันทึกของทีมตอนที่ยังว่างไว้ล่วงหน้า

3. เว็บและที่อยู่ที่ใช้ระหว่างอบรม

ต้องการ เปิดที่
อ่านชื่อบอร์ดจากสาย USB https://web.esphome.io (ใช้ Chrome หรือ Edge เท่านั้น)
เปิด Home Assistant ของทีม http:// ตามด้วยเลข IP ที่อ่านจากหน้าต่างเครื่อง Farm Workshop — ไม่ใช้ homeassistant.local และไม่ต้องใส่ :8123
ดูค่าจากบอร์ดโดยตรง ไม่ผ่าน Home Assistant http:// ตามด้วย IP ของบอร์ด หรือ http://<ชื่อบอร์ด>/ (ต้องมี / ปิดท้าย)
ใบงานหน้านี้ทั้งชุด https://arnans.github.io/iot-training/

4. สิ่งที่ผู้สอนแจกที่โต๊ะ

ของ มีอะไรอยู่บนนั้น
บัตรประจำทีม สีโซนของทีม · ชื่อและรหัส WiFi ของโซน · ชื่อผู้ใช้และรหัสผ่าน Home Assistant
ชุดอุปกรณ์ของทีม รายการทั้งหมดอยู่ในหน้าเริ่มต้นที่นี่
ใบบันทึกของทีมแบบพิมพ์ ฉบับเดียวกับใบบันทึกของทีมบนเว็บ

บัตรประจำทีมไม่มีชื่อบอร์ด ชื่อบอร์ดอ่านจากบอร์ดเองในกิจกรรมที่ 1 · ก่อนเริ่มให้ตรวจว่า สีบนบอร์ด สีบนบัตร และชื่อ WiFi ที่แล็ปท็อปเชื่อมต่อ ตรงกันทั้งหมด

5. หลังการอบรม — ถ้าอยากทำต่อเอง

ไม่ต้องใช้ในห้องอบรม แต่เป็นจุดเริ่มต้นสำหรับคนที่อยากสร้างระบบของตัวเองต่อ

แหล่งข้อมูล คืออะไร
Home Assistant คู่มือและวิธีติดตั้งอย่างเป็นทางการของซอฟต์แวร์ที่เราใช้
ESPHome ซอฟต์แวร์ที่อยู่ในบอร์ดของเรา ใช้เขียนค่าเซนเซอร์และรีเลย์เป็นไฟล์ YAML
ไฟล์ตั้งค่าบอร์ดของการอบรมนี้ ไฟล์ ESPHome ของบอร์ด GoGo-IoT และบอร์ดรีเลย์ที่เราใช้
ไฟล์ตั้งค่า Home Assistant ของการอบรมนี้ configuration.yaml ที่อยู่ในเครื่อง Farm Workshop
บอร์ด GoGo-IoT ข้อมูลฮาร์ดแวร์ของบอร์ดเซนเซอร์ที่ใช้ในห้องอบรม

เครื่อง Farm Workshop ในแล็ปท็อปยังใช้ต่อได้หลังจบการอบรม เปิด VirtualBox แล้วกด Start ได้เหมือนเดิม แต่บอร์ดจะหาไม่เจอเพราะ WiFi ของโซนมีเฉพาะในห้องอบรม ต้องแก้ WiFi ในบอร์ดด้วย ESPHome ก่อน
