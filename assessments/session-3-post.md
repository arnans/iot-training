# แบบทดสอบหลังเรียน ช่วงที่ 3

**เครือข่าย แดชบอร์ด และการออกแบบ**

- จำนวน 10 ข้อ: เลือกตอบ 8 ข้อ และคำตอบสั้น 2 ข้อ
- ข้อละ 1 คะแนน รวม 10 คะแนน
- เวลาที่แนะนำ: 15 นาที
- ทำรายบุคคล เลือกคำตอบที่ดีที่สุดเพียงข้อเดียวสำหรับข้อเลือกตอบ
- คำตอบสั้นให้พิมพ์ตามรูปแบบที่โจทย์กำหนด ไม่เว้นวรรคหัว–ท้าย

**ฉบับพร้อมเฉลย:** คำตอบและเกณฑ์ตรวจอยู่ท้ายแต่ละข้อ

### ข้อ 1 · เลือกตอบ

รหัสข้อ: `S3-POST-01`

โรงเรือนมีไฟเลี้ยงและ WiFi ครอบคลุม จุดวัดส่งข้อมูลเล็กน้อยทุกนาที บอร์ดรองรับ WiFi และไม่มีข้อกำหนดใช้แบตเตอรี่ วิธีใดใช้ประโยชน์จากโครงสร้างที่มีอยู่ได้ตรงที่สุด?

- **A.** เพิ่มเครือข่ายมือถือทุกจุดเพื่อให้กฎภายในทำงานได้
- **B.** ใช้ WiFi เดิม แล้วทดสอบความเสถียรที่จุดติดตั้งจริง
- **C.** เปลี่ยนเป็น LoRa เพราะข้อมูลเล็กจึงห้ามใช้ WiFi
- **D.** เปลี่ยนเป็น RS-485 เพราะระบบอัตโนมัติใช้ WiFi ไม่ได้

**เฉลยและเกณฑ์ตรวจ**

- คำตอบ: **B. ใช้ WiFi เดิม แล้วทดสอบความเสถียรที่จุดติดตั้งจริง**
- เหตุผล: ข้อกำหนดนี้มีเครือข่ายและไฟพร้อมแล้ว ไม่ต้องเพิ่มช่องทางอื่นเพียงเพราะเป็นงานฟาร์ม แต่ยังต้องทดลองพื้นที่จริง
- วัดความเข้าใจ: เลือกการสื่อสารโดยใช้เงื่อนไขของพื้นที่
- อ้างอิง: ใบงานช่วงที่ 3 หัวข้อ 7.3
- การให้คะแนน: เลือกคำตอบถูกได้ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คะแนน

### ข้อ 2 · เลือกตอบ

รหัสข้อ: `S3-POST-02`

- **A.** เซนเซอร์ → LoRa → เราเตอร์ WiFi เดิมโดยตรง โดยไม่เพิ่มตัวเชื่อม
- **B.** เซนเซอร์ → LoRa → ตัวรับที่บ้าน โดยถือว่ารับวิทยุได้ก็มี entity ให้อัตโนมัติ

**เฉลยและเกณฑ์ตรวจ**

- คำตอบ: **D. เซนเซอร์พร้อมไฟเลี้ยง → LoRa → ตัวรับพร้อมไฟเลี้ยงและตัวเชื่อมเข้า Home Assistant**

- อ้างอิง: ใบงานช่วงที่ 3 หัวข้อ 7.3
- การให้คะแนน: เลือกคำตอบถูกได้ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คะแนน

- คำตอบที่ยอมรับ (แต่ละคำตอบได้ 1 คะแนน): `3`, `3.0`, `3.00`, `๓`
- เหตุผล: สองแผงผลิตได้ 120 Wh ซึ่งไม่พอ ต้องใช้สามแผงได้ 180 Wh นี่เป็นการประมาณพลังงานรายวัน ไม่ยืนยันกำลังเริ่มต้น ความพร้อมกลางคืน หรือรายการซื้อจริง
- วัดความเข้าใจ: เลือกจำนวนอุปกรณ์เต็มชิ้นให้ผ่านข้อจำกัดพลังงาน
- อ้างอิง: ใบงานช่วงที่ 3 หัวข้อ 7.8
- การให้คะแนน: ตรงกับคำตอบที่ยอมรับได้ 1 คะแนน ตัดช่องว่างหัว–ท้ายและไม่แยกตัวพิมพ์เล็ก–ใหญ่ ผิดหรือไม่ตอบได้ 0 คะแนน
