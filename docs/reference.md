# อ้างอิง: เมนู Home Assistant ที่ใช้บ่อย

หน้านี้ไว้เปิดค้างระหว่างทำกิจกรรม

## เส้นทางเมนู

| ต้องการ | ไปที่ |
|---------|-------|
| อ่านชื่อบอร์ด | เสียบ USB → web.esphome.io (Chrome/Edge) → Connect → Logs & Console → กด **Reset device** ในหน้าเว็บ (ไม่ใช่ปุ่มบนบอร์ด) → อ่านกรอบ DEVICE NAME |
| เพิ่มบอร์ด ESPHome | Settings → Devices & services → กด card ของบอร์ดที่ลงท้ายด้วยหกตัวที่จดไว้ · ถ้าไม่มี card: + Add integration → ESPHome → Add device → Setup another instance of ESPHome → พิมพ์ชื่อบอร์ด (ไม่ต้องมี `.local`) |
| ดู entity ของบอร์ด | Settings → Devices & services → ESPHome → กดชื่ออุปกรณ์ |
| ดูค่าจากบอร์ดโดยตรง ไม่ผ่าน Home Assistant | เบราว์เซอร์เปิด `http://` ตามด้วย IP ของบอร์ดที่จดไว้ · หรือใช้ชื่อ `http://<ชื่อบอร์ด>/` (ต้องมี `/` ท้าย ไม่งั้นกลายเป็นค้นหาเว็บ) หรือ `<ชื่อบอร์ด>.local` |
| แก้แดชบอร์ด | เปิดแดชบอร์ด → ดินสอมุมบนขวา → + Add card → Done |
| สร้างแดชบอร์ดใหม่ | Settings → Dashboards → + Add dashboard → New dashboard from scratch |
| ดูกราฟย้อนหลัง | History → + Choose entity → เลือกช่วงเวลา |
| ดูว่าใครสั่งอะไรเมื่อไร | Logbook |
| สร้าง automation | Settings → Automations & scenes → + Create automation → Create new automation |
| แก้หรือปิด automation | Settings → Automations & scenes → กดชื่อ (สวิตช์ทางขวาคือเปิดปิดกฎ) |
| ดูว่า automation ทำงานล่าสุดเมื่อไร | กดชื่อ automation → Last triggered หรือกด ⋮ → Traces |
| ดูข้อความแจ้งเตือน | ไอคอนกระดิ่งมุมล่างซ้าย |

## trigger, condition, action ที่ใช้ในหลักสูตร

| ชื่อในเมนู | ใช้เมื่อ | ตัวอย่าง |
|-----------|---------|----------|
| Entity → Numeric state | ค่าตัวเลข (แอนะล็อก) ข้ามเกณฑ์ | แสง Below 200 · ความชื้นอากาศ Below 45 |
| Entity → State | สถานะ (ดิจิทัล) เปลี่ยน หรือคงสถานะนานเกิน | สวิตช์ลูกลอย To (สถานะน้ำต่ำ) · ปั๊ม To On For 30 วินาที · ความชื้นอากาศ To unavailable |
| Condition → State | ให้กฎทำงานเฉพาะเมื่ออีก entity อยู่ในสถานะที่กำหนด | รดน้ำได้เฉพาะเมื่อสวิตช์ลูกลอยบอกว่าน้ำพอ |
| Condition → Time | จำกัดช่วงเวลาที่กฎทำงาน | After 06:00 Before 18:00 |
| Action → Switch → Turn on / Turn off | สั่ง actuator | สวิตช์ปั๊ม |
| Action → Send a persistent notification | แจ้งเตือนบนหน้าจอ Home Assistant | ปั๊มเดินเกินเวลา |

## card ที่ใช้ในหลักสูตร

| card | ใช้แสดง |
|------|---------|
| **Gauge** | ค่าปัจจุบันหนึ่งค่า ตั้ง Severity ให้เปลี่ยนสีตามเกณฑ์ได้ |
| **History graph** | แนวโน้มย้อนหลัง ตั้งจำนวนชั่วโมงได้ |
| **Entities** | รายการหลายค่าและหลายสวิตช์ในใบเดียว |
| **Tile** | ปุ่มใหญ่หนึ่งปุ่ม เหมาะกับการกดบนโทรศัพท์ |

## เมื่อติดปัญหา

| อาการ | ตรวจตามลำดับ |
|-------|--------------|
| เพิ่มบอร์ดไม่สำเร็จ | **สีในชื่อบอร์ดตรงกับสีโซนของทีมหรือไม่** · แล็ปท็อปอยู่บน `farm-laptop-สีเดียวกัน` หรือไม่ · ไฟบนบอร์ดติดหรือไม่ · ถ้าพิมพ์ชื่อเอง พิมพ์ครบหกตัวท้ายหรือไม่ (ไม่ต้องมี `.local`) |
| หน้าต่าง log ใน web.esphome.io ว่างเปล่า | บอร์ดทำงานอยู่แล้วจึงไม่พิมพ์อะไรใหม่ กด **Reset device** ในหน้าเว็บ อย่าถอดสายหรือกดปุ่มบนบอร์ด |
| พิมพ์ชื่อบอร์ดแล้วไม่เจอ | เปิด web.esphome.io → Reset device → อ่านบรรทัด `IP ADDRESS` ที่ขึ้นหลังต่อ WiFi แล้วพิมพ์ IP นั้นแทนชื่อ |
| entity เป็น unavailable | บอร์ดยังเสียบไฟอยู่หรือไม่ · เราเตอร์ทำงานหรือไม่ · รอ 30 วินาทีให้บอร์ดต่อใหม่ |
| entity หายเป็นพัก ๆ หรือค่ามาช้า | ดู entity `ความแรงสัญญาณ WiFi` ของบอร์ด หน่วย dBm เป็นเลขติดลบ **ยิ่งใกล้ 0 ยิ่งแรง** −50 ดีมาก · −65 พอใช้ · −75 อ่อน ค่าอาจหายเป็นพัก ๆ · −85 ใช้ไม่ได้ ลองขยับบอร์ดหรือแล็ปท็อปให้พ้นสิ่งกีดขวางโลหะ แล้วบอกผู้สอน |
| automation ไม่ทำงาน | สวิตช์ของกฎเปิดอยู่หรือไม่ · ค่า **ข้าม** เกณฑ์จริงหรือยัง · ดู Traces ว่าหยุดที่ condition ไหน |
| บอร์ดรีเลย์ไม่ติดไฟเลย | adapter เสียบหรือยัง · จอตัวควบคุมติดหรือไม่ · สายจากคู่โหลดของตัวควบคุมถึงแผงต่อสายและขั้วไฟเข้าของบอร์ดครบหรือไม่ · ถ้าจอติดแต่โหลดไม่ออก ให้บอกผู้สอน (โหมดโหลดของตัวควบคุม) |
| ปั๊มไม่เดินแม้สวิตช์เป็น On | ดู entity `ปั๊มกำลังทำงาน (pump running)` ถ้าเป็น Off ทั้งที่สวิตช์ On แปลว่ารีเลย์ปิดวงจรแล้วแต่ปั๊มไม่สั่นจริง (หรือบอร์ด GoGo-IoT อยู่ไกลปั๊ม ให้ขยับเข้าใกล้ หรือเลือก `ความไวตรวจจับปั๊ม` เป็น สูง) · ไฟแสดงสถานะรีเลย์ติดหรือไม่ · สายเข้า COM และ NO แน่นหรือไม่ (ไม่ใช่ NC) · สายลบของปั๊มเข้าแถวลบหรือไม่ · ปั๊มจุ่มน้ำหรือไม่ |
| บอร์ดรีเลย์ติดแต่ไม่เข้าเครือข่าย | ดูไฟ **LED** บนบอร์ด ถ้า**กะพริบ** คือต่อ WiFi ไม่ได้ (หลังหลุดจริง ไฟจะเริ่มกะพริบช้าไปหลายวินาที) · สีในชื่อบอร์ดตรงกับสีโซนของทีมหรือไม่ · หลังต่อไฟใหม่ รอถึงหนึ่งนาที · เสียบ USB เข้ากับแล็ปท็อปเพื่ออ่าน log ได้เลย **ไม่ต้องถอดไฟ 12V ออกก่อน** |
| ไฟแสดงสถานะรีเลย์ หรือปั๊ม เปิดปิดถี่ | ค่าปิดยังเท่ากับค่าเปิดอยู่หรือไม่ (ต้องมี hysteresis) |
| ครอบบอร์ดแล้วรีเลย์ไม่ตอบทันที | รอให้ครบรอบส่งค่าของเซนเซอร์แสง (ดู update_interval ในไฟล์ตั้งค่า) · ค่าข้ามเกณฑ์จริงหรือแค่ใกล้ |
| โทรศัพท์เปิด Home Assistant ของแล็ปท็อปไม่ได้ | โทรศัพท์อยู่บน `farm-laptop-สีเดียวกับแล็ปท็อป` หรือไม่ (อินเทอร์เน็ตมือถือใช้ไม่ได้กับข้อนี้) · พิมพ์ **ที่อยู่ (IP) ที่จดไว้ในใบบันทึก** ไม่ใช่ localhost และไม่ใช่ `homeassistant.local` (ชื่อนี้ซ้ำกันทั้งห้อง อาจไปเจอเครื่องของทีมอื่น) · ถ้าเลขที่จดไว้ใช้ไม่ได้ ให้อ่านที่อยู่จากหน้าจอ VM ใหม่ |
| จอตัวควบคุมการชาร์จไม่ติด | ต่อ adapter เข้าคู่ขั้วแบตเตอรี่ (คู่กลาง) หรือไม่ · ขั้วบวกลบสลับหรือไม่ · adapter เสียบปลั๊กหรือยัง |
