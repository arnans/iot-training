# แผนแบบทดสอบก่อน–หลังเรียน

ฉบับปรับปรุงเพื่อวัดความเข้าใจจากการทำนาย วินิจฉัย และประยุกต์ใช้ แทนการตัดตัวเลือกที่ผิดอย่างเห็นได้ชัด

## รูปแบบและเกณฑ์

- [ไฟล์ Markdown พร้อมเฉลย](../assessments/README.md) รวม 6 ชุด 45 ข้อ
- ก่อนเรียนช่วงละ 4 MCQ + 1 คำตอบสั้น หลังเรียนช่วงละ 8 MCQ + 2 คำตอบสั้น
- ข้อละ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คำตอบสั้นตรวจจากรายการคำตอบที่ยอมรับ ไม่ใช้การตีความเรียงความ
- แต่ละข้อมีเฉลย เหตุผล สิ่งที่วัด และหัวข้อใบงานอ้างอิง
- ก่อนเรียนวัดแนวคิดตั้งต้น หลังเรียนใช้สถานการณ์และหลักฐานหลายส่วน ตัวลวงเน้นความเข้าใจคลาดเคลื่อนที่เกี่ยวข้องกับเนื้อหา
- ยังไม่ทราบ LMS จึงต้องตั้งค่าหรือแปลงไฟล์และทดลองตรวจคำตอบจริงก่อนเปิดใช้

## ขอบเขตการวัด

เป้าหมายหลัก: ช่วง 1 แยก Input / Logic / Output และเลือกอุปกรณ์; ช่วง 2 สร้างกฎและออกแบบการป้องกัน; ช่วง 3 วิเคราะห์เครือข่ายและใช้ข้อมูลบนแดชบอร์ด โดยมีพลังงานประกอบการออกแบบ

### ช่วงที่ 1 — ก่อนเรียน

1. แยกหน้าที่ของส่วนตัดสินใจเมื่อโจทย์เปลี่ยน
2. แยกการตัดสินใจด้วยคนกับโปรแกรม
3. ใช้ความเข้าใจเรื่องรีเลย์และพลังงานทำนายผล
4. ตีความข้อจำกัดของการวัดสองสถานะ
5. จำแนกหน้าที่จากการกระทำ

### ช่วงที่ 1 — หลังเรียน

1. ใช้หลักฐานแยกปัญหาการรับค่ากับปัญหาการสั่งงาน
2. วินิจฉัยส่วน Logic จากผลทดสอบ Input และ Output
3. แยกสถานะคำสั่งออกจากหลักฐานการทำงานจริง
4. แยกตัวแปรที่วัดออกจากตัวแปรที่ต้องการใช้ตัดสินใจ
5. ตระหนักว่าค่าที่แสดงขึ้นกับสภาพของเซนเซอร์
6. เลือกอุปกรณ์จากความต้องการและชนิดสัญญาณที่ระบุ
7. ตรวจเงื่อนไขทางไฟฟ้าร่วมกันสองข้อ
8. ติดตามเส้นทาง Input → Logic → Output ผ่าน entity
9. ใช้พฤติกรรมวงจรเลือกหน้าสัมผัส
10. ติดตามผลของกฎเปิดและปิดตลอดลำดับข้อมูล

### ช่วงที่ 2 — ก่อนเรียน

1. แยกเหตุการณ์ข้ามเกณฑ์จากสถานะต่ำกว่าเกณฑ์
2. ทำนายความสัมพันธ์ระหว่าง trigger กับ condition
3. เข้าใจการคงสถานะในช่วง hysteresis
4. แยกการป้องกันการเริ่มกับการหยุดเมื่อมีอันตราย
5. นับเหตุการณ์แทนการนับค่าที่ผ่านเงื่อนไข

### ช่วงที่ 2 — หลังเรียน

1. ติดตามสถานะตลอดวงจร hysteresis
2. เลือกโครงสร้างกฎที่ครอบคลุมหลายลำดับเหตุการณ์
3. แยก OR ของ trigger ออกจาก AND ของ condition
4. แยกการอนุญาตรอบใหม่จากการหยุดรอบปัจจุบัน
5. หาเหตุการณ์ที่กฎป้องกันเดิมยังไม่ครอบคลุม
6. แยกความผิดพลาดของการตรวจจับออกจากอุปกรณ์ไม่ทำงาน
7. ใช้ Traces แยกเหตุที่ทำให้ระบบหยุด
8. ถ่ายโอนแนวคิดการป้องกันไปยังอุปกรณ์ใหม่และหาจุดพึ่งพาร่วม
9. ติดตาม hysteresis ในบริบทปั๊มโดยไม่ใช้สูตรแทนความเข้าใจ
10. เข้าใจ For ว่าเป็นระยะเวลาต่อเนื่องของสถานะ

### ช่วงที่ 3 — ก่อนเรียน

1. ระบุขอบเขตผลกระทบของการเชื่อมต่อที่ขัดข้อง
2. แยกข้อจำกัดด้านระยะทางออกจากปริมาณข้อมูล
3. ตีความข้อมูลตามสิ่งที่วัดโดยไม่ขยายข้อสรุป
4. เลือกโครงสร้างหน้าจอจากงานที่ต้องทำ
5. เชื่อมระยะเวลาที่ต้องสำรองกับความต้องการพลังงาน

### ช่วงที่ 3 — หลังเรียน

1. เลือกการสื่อสารโดยใช้เงื่อนไขของพื้นที่
2. ตรวจความครบถ้วนของเส้นทางข้อมูลและไฟเลี้ยง
3. วิเคราะห์จุดพึ่งพาของสถาปัตยกรรมสองแบบ
4. แยก remote access ออกจากการย้ายระบบประมวลผล
5. อ่านข้อมูลหลายแหล่งและระบุขอบเขตข้อสรุป
6. อธิบายข้อมูลขาดจากวงจรการบันทึก
7. เลือกการนำเสนอให้ตรงกับความหมายของ entity
8. ใช้ผลทดสอบผู้ใช้วินิจฉัยและปรับแดชบอร์ด
9. เชื่อมการใช้พลังงานต่อช่วงกับระยะสำรอง
10. เลือกจำนวนอุปกรณ์เต็มชิ้นให้ผ่านข้อจำกัดพลังงาน

## การตรวจคุณภาพหลังทดลองใช้

ตรวจสัดส่วนผู้ตอบถูก ตัวเลือกผิดที่มีคนเลือก และข้อที่ผู้เรียนตีความต่างกัน ใช้ผลนี้ปรับตัวลวงหรือถ้อยคำ ข้อที่เขียนให้ต้องใช้แนวคิดไม่ได้รับประกันว่าจะจำแนกระดับความเข้าใจได้ดีจนกว่าจะมีข้อมูลจากผู้เรียนจริง ไม่ใช้ผลต่างร้อยละก่อน–หลังเพียงอย่างเดียวสรุปขนาดการเรียนรู้ เพราะจำนวนข้อและความยากต่างกัน
