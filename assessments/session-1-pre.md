# แบบทดสอบก่อนเรียน ช่วงที่ 1

**รับรู้ ตัดสินใจ สั่งการ**

- จำนวน 5 ข้อ: เลือกตอบ 4 ข้อ และคำตอบสั้น 1 ข้อ
- ข้อละ 1 คะแนน รวม 5 คะแนน
- เวลาที่แนะนำ: 5–7 นาที
- ทำรายบุคคล เลือกคำตอบที่ดีที่สุดเพียงข้อเดียวสำหรับข้อเลือกตอบ
- คำตอบสั้นให้พิมพ์ตามรูปแบบที่โจทย์กำหนด ไม่เว้นวรรคหัว–ท้าย

**ฉบับพร้อมเฉลย:** คำตอบและเกณฑ์ตรวจอยู่ท้ายแต่ละข้อ

### ข้อ 1 · เลือกตอบ

รหัสข้อ: `S1-PRE-01`

ระบบหนึ่งอ่านค่าแสง เปรียบเทียบกับเกณฑ์ แล้วสั่งรีเลย์ ถ้าจะเปลี่ยนจาก “เปิดเมื่อมืด” เป็น “เปิดเมื่อสว่าง” โดยใช้อุปกรณ์เดิม ต้องเปลี่ยนส่วนใดเป็นหลัก?

- **A.** วิธีรับค่าจากเซนเซอร์
- **B.** เงื่อนไขที่ใช้ตัดสินใจ
- **C.** แรงดันเลี้ยงรีเลย์
- **D.** อุปกรณ์ที่รับคำสั่ง

**เฉลยและเกณฑ์ตรวจ**

- คำตอบ: **B. เงื่อนไขที่ใช้ตัดสินใจ**
- เหตุผล: งานรับค่าและอุปกรณ์ปลายทางเหมือนเดิม สิ่งที่เปลี่ยนคือกฎในส่วน Logic
- วัดความเข้าใจ: แยกหน้าที่ของส่วนตัดสินใจเมื่อโจทย์เปลี่ยน
- อ้างอิง: ใบงานช่วงที่ 1 หัวข้อ 3.4
- การให้คะแนน: เลือกคำตอบถูกได้ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คะแนน

### ข้อ 2 · เลือกตอบ

รหัสข้อ: `S1-PRE-02`

ชุด A ให้คนอ่านค่าแสงแล้วกดเปิดไฟ ชุด B ให้โปรแกรมอ่านค่าเดียวกันแล้วสั่งไฟเอง ทั้งสองชุดใช้เซนเซอร์และหลอดเดียวกัน ข้อใดอธิบายความต่างได้ตรงที่สุด?

- **A.** A ไม่มี Input แต่ B มี Input
- **B.** A ไม่มี Output แต่ B มี Output
- **C.** A มีคนเป็นผู้ตัดสินใจ ส่วน B ใช้กฎในโปรแกรม
- **D.** A ใช้ข้อมูลแอนะล็อก ส่วน B ใช้ข้อมูลดิจิทัลเสมอ

**เฉลยและเกณฑ์ตรวจ**

- คำตอบ: **C. A มีคนเป็นผู้ตัดสินใจ ส่วน B ใช้กฎในโปรแกรม**
- เหตุผล: ทั้งสองชุดมีการรับข้อมูลและสั่งงาน ต่างกันที่ผู้ทำหน้าที่ Logic ไม่อาจสรุปชนิดสัญญาณจากการมีคนหรือโปรแกรม
- วัดความเข้าใจ: แยกการตัดสินใจด้วยคนกับโปรแกรม
- อ้างอิง: ใบงานช่วงที่ 1 หัวข้อ 3.4
- การให้คะแนน: เลือกคำตอบถูกได้ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คะแนน

### ข้อ 3 · เลือกตอบ

รหัสข้อ: `S1-PRE-03`

รีเลย์รับไฟเลี้ยงแล้วและได้ยินเสียงคลิกเมื่อสั่ง On แต่หลอดที่ต่อผ่านหน้าสัมผัสยังไม่มีแหล่งจ่ายไฟของหลอดเอง ข้อใดคาดว่าจะเกิดขึ้น?

- **A.** หลอดไม่ติด แม้หน้าสัมผัสรีเลย์จะเปลี่ยนตำแหน่ง
- **B.** หลอดติดโดยรับไฟจากคำสั่ง On
- **C.** หลอดติดเพราะไฟเลี้ยงรีเลย์ผ่านไปยังหลอดเสมอ
- **D.** หลอดติดเฉพาะขณะที่ได้ยินเสียงคลิก

**เฉลยและเกณฑ์ตรวจ**

- คำตอบ: **A. หลอดไม่ติด แม้หน้าสัมผัสรีเลย์จะเปลี่ยนตำแหน่ง**
- เหตุผล: การสั่งรีเลย์เปลี่ยนหน้าสัมผัสไม่ได้เป็นการจ่ายพลังงานให้โหลด วงจรหลอดยังต้องมีแหล่งจ่าย
- วัดความเข้าใจ: ใช้ความเข้าใจเรื่องรีเลย์และพลังงานทำนายผล
- อ้างอิง: ใบงานช่วงที่ 1 หัวข้อ 2.2–2.4
- การให้คะแนน: เลือกคำตอบถูกได้ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คะแนน

### ข้อ 4 · เลือกตอบ

รหัสข้อ: `S1-PRE-04`

ถังสองใบติดลูกลอยไว้ที่ระดับเดียวกัน ถังหนึ่งมีน้ำสูงกว่าลูกลอยเล็กน้อย อีกถังมีน้ำสูงกว่ามาก ถ้าใช้ลูกลอยแบบสองสถานะเพียงตัวเดียวต่อถัง จะแยกสองกรณีนี้ได้หรือไม่?

- **A.** ได้ เพราะระดับน้ำสูงทำให้ค่า Wet มากขึ้น
- **B.** ได้ ถ้าอ่านสถานะลูกลอยให้ถี่ขึ้น
- **C.** ไม่ได้ เพราะต้องใช้ลูกลอยที่ต่อผ่านอินเทอร์เน็ต
- **D.** ไม่ได้ เพราะทั้งสองกรณีให้สถานะน้ำถึงลูกลอยเหมือนกัน

**เฉลยและเกณฑ์ตรวจ**

- คำตอบ: **D. ไม่ได้ เพราะทั้งสองกรณีให้สถานะน้ำถึงลูกลอยเหมือนกัน**
- เหตุผล: สถานะสองแบบไม่แสดงปริมาณที่สูงกว่าจุดติดตั้ง การอ่านถี่ขึ้นไม่เพิ่มข้อมูลชนิดที่เซนเซอร์ไม่ได้วัด
- วัดความเข้าใจ: ตีความข้อจำกัดของการวัดสองสถานะ
- อ้างอิง: ใบงานช่วงที่ 1 หัวข้อ 1.4
- การให้คะแนน: เลือกคำตอบถูกได้ 1 คะแนน ผิดหรือไม่ตอบได้ 0 คะแนน

### ข้อ 5 · คำตอบสั้น

รหัสข้อ: `S1-PRE-05`

ในลำดับ “วัดอุณหภูมิ → เปรียบเทียบกับ 35 °C → สั่งพัดลม” ส่วน “เปรียบเทียบกับ 35 °C” ตรงกับคำใด? ตอบหนึ่งคำจาก Input, Logic, Output

คำตอบ: ____________________

**เฉลยและเกณฑ์ตรวจ**

- คำตอบที่ยอมรับ (แต่ละคำตอบได้ 1 คะแนน): `Logic`
- เหตุผล: การเปรียบเทียบเพื่อเลือกคำสั่งเป็น Logic ไม่ใช่การรับค่าหรือการทำงานของอุปกรณ์
- วัดความเข้าใจ: จำแนกหน้าที่จากการกระทำ
- อ้างอิง: ใบงานช่วงที่ 1 หัวข้อ 3.4
- การให้คะแนน: ตรงกับคำตอบที่ยอมรับได้ 1 คะแนน ตัดช่องว่างหัว–ท้ายและไม่แยกตัวพิมพ์เล็ก–ใหญ่ ผิดหรือไม่ตอบได้ 0 คะแนน
