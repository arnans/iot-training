IoT ในฟาร์มอัจฉริยะ

ใบงานและไฟล์ทั้งหมดสำหรับการอบรมสามช่วง เปิดได้ทั้งบนโทรศัพท์และแล็ปท็อป

เริ่มที่นี่

ทำก่อนวันอบรมอย่างน้อย 3 วัน ใช้เวลาราว 30 นาที ไม่รวมเวลาดาวน์โหลด

ก่อนการอบรม เตรียมแล็ปท็อป ติดตั้ง VirtualBox นำเข้าเครื่อง Farm Workshop และเปิด Home Assistant ให้ได้ อ้างอิง รวมไฟล์และลิงก์ ทุกไฟล์ที่ต้องดาวน์โหลดและทุกลิงก์ที่ใช้ รวมไว้ที่เดียว

ใบงานระหว่างการอบรม

แต่ละช่วงต่อยอดจากช่วงก่อนหน้า และใช้ชุดอุปกรณ์ชุดเดิมตลอด

ช่วงที่ 1 รับรู้ ตัดสินใจ สั่งการ อ่านค่าเซนเซอร์บนแดชบอร์ด ต่อวงจร 12V และสั่งปั๊มน้ำจากแล็ปท็อปและโทรศัพท์ ช่วงที่ 2 ควบคุมอัตโนมัติและ Fail-safe เปิดไฟเองเมื่อมืดโดยไม่กะพริบ รดน้ำเองเมื่ออากาศแห้ง และหยุดเองเมื่อน้ำหมด ช่วงที่ 3 แดชบอร์ดและออกแบบระบบ อ่านกราฟย้อนหลัง สร้างแดชบอร์ดสำหรับผู้ใช้จริง และร่างระบบของฟาร์มเราเอง

ใช้ระหว่างทำกิจกรรม

อ้างอิง เมนูและวิธีแก้ปัญหา เมนู Home Assistant ที่ใช้บ่อย และอาการที่เจอบ่อยพร้อมวิธีแก้ ของทีม ใบบันทึกของทีม รวมคำตอบทุกช่องและแบบร่างระบบ พิมพ์ไว้ล่วงหน้า หรือกรอกบนเว็บแล้วดาวน์โหลด
ก่อนจบการอบรม เปิดใบบันทึกของทีม กด ดาวน์โหลดคำตอบ ส่งไฟล์ให้ผู้สอน และกด พิมพ์ / บันทึก PDF เก็บไว้อ้างอิง
