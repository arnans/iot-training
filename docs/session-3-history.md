**20 นาที**

**อุปกรณ์ที่ใช้** แล็ปท็อป

เปิดข้อมูลที่เริ่มบันทึกไว้ตั้งแต่ช่วงที่ 2 ที่ผ่านมา หาว่าการเปลี่ยนแปลงบนกราฟตรงกับการทดลองใด แล้วคิดว่าถ้าเกิดในฟาร์มจริงควรตรวจอะไร

### การเปิดกราฟดูข้อมูลย้อนหลัง { #hist-1 }


**เลือกข้อมูลและช่วงเวลา**

1. เปิด **History** จากเมนูด้านซ้าย
2. กด **Add target** แล้วเลือกความชื้นอากาศ แสง และ **สวิตช์ของบอร์ดรีเลย์**
3. เลือกช่วงเวลาตั้งแต่เริ่มช่วงที่ 2 จนถึงปัจจุบัน กราฟแสดงได้เฉพาะช่วงที่มีข้อมูลบันทึกไว้

### อ่านค่าต่ำสุด–สูงสุด { #hist-3 }
