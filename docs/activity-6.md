### 6.3 สร้างแดชบอร์ด { #a6-2 }


**สร้างแดชบอร์ด**

1. เปิด **Settings → Dashboards → + Add dashboard → New dashboard from scratch** ตั้งชื่อ เช่น `แปลง 1`

**เพิ่มการ์ด**

2. เปิดแดชบอร์ดใหม่ กดไอคอนดินสอ แล้วเพิ่มการ์ดตามตาราง

| การ์ดที่ต้องมี | เลือกข้อมูล | ชื่อที่ใช้บนจอ |
|---|---|---|
| **Gauge** | ความชื้นอากาศ | ความชื้นอากาศ (%) |
| **Tile** | สวิตช์ลูกลอย | ระดับน้ำที่ลูกลอย |
| **Tile** | สวิตช์รีเลย์ | สั่งปั๊ม |
| **Tile** | `Pump Auto Mode` (จากช่วงที่ 2) | โหมด Auto / Manual |

**จัดหน้าจอ**

3. จัดการ์ดสำคัญไว้ด้านบน แล้วกด **Done**

**(ไม่บังคับทำ) เพิ่มการ์ดอื่น**

4. เพิ่มการ์ด **Entities** รวมกฎรดน้ำและกฎป้องกันที่สร้างไว้ เพิ่ม **History graph** ตั้ง **Hours to show: 24** หรือปรับสี Gauge ตามเกณฑ์ของกลุ่ม

> ลูกลอยแสดงได้ว่าน้ำถึงจุดติดตั้งหรือไม่ ส่วนสวิตช์ปั๊มแสดงสถานะรีเลย์ ตั้งชื่อไม่ให้ผู้ใช้เข้าใจว่าเป็นปริมาตรน้ำหรือหลักฐานว่าปั๊มเดินจริง

[↑ กลับไปที่ใบงาน](#a6){ .ws-back }

### 6.4 ให้ผู้อื่นทดลองใช้ { #a6-3 }


**ให้ผู้อื่นลองใช้**

1. เปิดแดชบอร์ดบนโทรศัพท์ ให้คนจากกลุ่มข้าง ๆ หรือคนที่ไม่ได้ช่วยสร้างทดลองดู โดยยังไม่อธิบาย
2. ให้เขาอธิบายทีละการ์ดว่าแสดงอะไรหรือสั่งอะไร แล้วลองถาม: **ความชื้นเท่าไร · น้ำถึงระดับลูกลอยหรือไม่ · ปุ่มสั่งปั๊มอยู่ไหน · ตอนนี้เป็นโหมด Auto หรือ Manual**

**ปรับปรุงและทดสอบซ้ำ**

3. หากให้ผู้ใช้ลองแล้วตอบไม่ได้หรือเข้าใจผิด ให้ปรับชื่อหรือตำแหน่งการ์ด แล้วให้ลองใหม่

[↑ กลับไปที่ใบงาน](#a6){ .ws-back }
