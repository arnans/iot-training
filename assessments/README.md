# แบบทดสอบรายบุคคลก่อน–หลังเรียน

แบบทดสอบภาษาไทยสำหรับหลักสูตร IoT ในฟาร์ม รวม **6 ชุด 45 ข้อ** จัดทำตามใบงานช่วงที่ 1–3

## ไฟล์แบบทดสอบพร้อมเฉลย

ทั้ง 6 ไฟล์มีเฉลย เหตุผล คำตอบสั้นที่ยอมรับ และเกณฑ์ให้คะแนนอยู่ท้ายแต่ละข้อ ใช้เป็นต้นฉบับสำหรับจัดทำข้อสอบใน LMS

| ช่วง | ก่อนเรียน | หลังเรียน | เนื้อหาหลัก |
|---|---|---|---|
| 1 | [5 ข้อ](session-1-pre.md) | [10 ข้อ](session-1-post.md) | Input / Logic / Output เซนเซอร์ รีเลย์ และการเลือกอุปกรณ์ |
| 2 | [5 ข้อ](session-2-pre.md) | [10 ข้อ](session-2-post.md) | Trigger / condition การแยกเกณฑ์เปิด–ปิด และการป้องกันเมื่อระบบขัดข้อง |
| 3 | [5 ข้อ](session-3-pre.md) | [10 ข้อ](session-3-post.md) | เครือข่ายภายใน การเข้าถึงจากภายนอก ข้อมูลย้อนหลัง แดชบอร์ด และพลังงาน |

- ก่อนเรียนแต่ละชุด: MCQ 4 ข้อ + คำตอบสั้น 1 ข้อ รวม 5 คะแนน
- หลังเรียนแต่ละชุด: MCQ 8 ข้อ + คำตอบสั้น 2 ข้อ รวม 10 คะแนน
- MCQ มี 4 ตัวเลือก ถูกเพียงข้อเดียว คำตอบสั้นเป็นตัวเลขหรือชื่อขั้วที่กำหนดชัดเจน
- แนะนำให้ทำก่อนและหลังแต่ละช่วงเป็นรายบุคคล ใช้เวลา 5–7 นาทีและ 15 นาทีตามลำดับ
- ยังไม่ได้กำหนดคะแนนผ่านหรือจำนวนครั้งที่ทำได้ ผู้จัดสามารถกำหนดใน LMS ตามนโยบายการอบรม

## ไฟล์สำหรับผู้สอน

[เฉลยและเกณฑ์ตรวจ](answer-key.md) เป็นฉบับรวมสำหรับเปิดดูคำตอบทุกข้ออย่างรวดเร็ว ข้อมูลเดียวกันฝังอยู่ในไฟล์แบบทดสอบแต่ละชุดแล้ว

## การนำเข้า LMS

ไฟล์ Markdown เป็นต้นฉบับสำหรับจัดทำข้อสอบ **ยังไม่ใช่แพ็กเกจนำเข้าของ LMS ใดโดยเฉพาะ** เมื่อทราบระบบปลายทาง ให้แปลงหรือกรอกข้อสอบตามรูปแบบที่ระบบรองรับ โดยใช้รหัสข้อคงเดิม เช่น `S2-POST-05`

1. สร้างแบบทดสอบ 6 ชุดตามชื่อไฟล์ แยกก่อนเรียนและหลังเรียนของแต่ละช่วง
2. ตั้ง MCQ เป็นแบบเลือกคำตอบเดียวและใช้เฉลยที่กำหนด ข้อละ 1 คะแนน ผิดหรือไม่ตอบได้ 0
3. ตั้ง short answer เป็นการจับคู่คำตอบกับรายการที่ยอมรับในเฉลย โดยไม่ให้คะแนนจากคำบางส่วน ไม่ใช้ wildcard
4. สำหรับคำตอบ `NO` ให้ไม่แยกตัวพิมพ์เล็ก–ใหญ่ หากระบบไม่มีตัวเลือกนี้ ให้เพิ่ม `NO`, `no`, `No`, `nO` เป็นคำตอบถูกทั้งหมด
5. หากเลือกใช้ชนิด numeric สำหรับคำตอบตัวเลข ให้กำหนดค่าตามเฉลยและค่าคลาดเคลื่อนเป็น 0 ตรวจด้วยว่าระบบรองรับเลขไทยหรือไม่ หากไม่รองรับ ให้ใช้ short answer พร้อมรายการคำตอบที่ยอมรับตามเฉลย
6. ตั้งเวลาแสดงเฉลยตามแผนการวัดผล แนะนำให้เปิดหลังปิดแบบทดสอบหลังเรียน
7. ทดลองส่งคำตอบถูก ผิด เว้นว่าง เลขไทย เลขทศนิยม และตัวพิมพ์เล็ก–ใหญ่ ตรวจคะแนนและภาษาไทยก่อนเปิดให้ผู้เรียนใช้จริง

ถ้าเก็บไฟล์ใน Git repository ที่เปิดสาธารณะ เฉลยก็เป็นสาธารณะเช่นกัน การซ่อนเฉลยใน LMS ไม่ได้ทำให้ไฟล์ใน repository เป็นความลับ

## การจับคู่หัวข้อก่อน–หลังเรียน

| ช่วง | ข้อก่อนเรียน | ข้อหลังเรียนที่วัดหัวข้อใกล้เคียง |
|---|---|---|
| 1 | 1–2: รับข้อมูลและตัดสินใจ | 1–3: แยกหน้าที่ของระบบในสถานการณ์ใหม่ |
| 1 | 3: หน้าที่รีเลย์ | 8–9: ตรวจผลจริงและเลือกหน้าสัมผัส |
| 1 | 4: ข้อจำกัดลูกลอย | 5–6: อ่านสถานะและเลือกเซนเซอร์ |
| 1 | 5: อ่านแรงดันอุปกรณ์ | 7: เลือกแหล่งจ่ายจากแรงดันและกระแส |
| 2 | 1: เหตุการณ์เริ่มกฎ | 2–3: เพิ่ม trigger เวลาและตรวจแสง |
| 2 | 2: เงื่อนไขกั้นคำสั่ง | 4–5: โหมดควบคุมและเงื่อนไขระดับน้ำ |
| 2 | 3: แยกเกณฑ์ | 1, 9: ทำนายสถานะและคำนวณระยะห่างเกณฑ์ |
| 2 | 4: หยุดเมื่อไม่ปลอดภัย | 5–8: ป้องกันและระบุข้อจำกัดเมื่อเกิดปัญหา |
| 2 | 5: เวลาจำกัดปั๊ม | 10: คำนวณเวลาที่เหลือ |
| 3 | 1: เครือข่ายภายใน | 3–4: อินเทอร์เน็ตดับและการเข้าถึงผ่านคลาวด์ |
| 3 | 2: ปัจจัยเลือกการสื่อสาร | 1–2: เลือกและสำรวจเครือข่ายตามสถานการณ์ |
| 3 | 3: คำสั่งไม่ใช่ผลจริง | 5, 7: อ่านหลักฐานและตั้งชื่อการ์ดให้ตรงข้อมูล |
| 3 | 4: ออกแบบตามผู้ใช้ | 7–8: ตั้งชื่อและทดสอบแดชบอร์ด |
| 3 | 5: พลังงาน | 9–10: คำนวณรายวันและจำนวนแผง |

ข้อหลังเรียนเพิ่มเติมช่วยวัดการนำไปใช้ ไม่ใช่ข้อสอบคู่ขนานที่ผ่านการเทียบความยาก คะแนนก่อน–หลังจึงใช้ประกอบการดูพัฒนาการ และควรดูผลรายหัวข้อร่วมด้วย
