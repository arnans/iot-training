# IoT ในฟาร์มอัจฉริยะ

**ใบงานสำหรับผู้เข้าร่วม** · หลักสูตร "นวัตกรเกษตรอัจฉริยะ AIoT สำหรับเกษตรแม่นยำ" 

![ระบบที่เราจะสร้าง: บอร์ด GoGo-IoT พร้อมสวิตช์ลูกลอยในแก้วน้ำ บอร์ดรีเลย์ต่อปั๊มน้ำ 12V และแดชบอร์ด Home Assistant บนแล็ปท็อป](images/placeholder.png){ width="60%" }

ตลอดหลักสูตรนี้ ทีมของเราจะสร้างระบบรดน้ำอัตโนมัติขึ้นหนึ่งระบบ (และแวะทำระบบไฟสวนเล็ก ๆ อีกหนึ่งระบบ) แล้วใช้ชุดอุปกรณ์ชุดเดียวกันนี้เรียนทุกเรื่องที่ระบบ IoT ในฟาร์มต้องมี ตั้งแต่การอ่านค่าเซนเซอร์ การเดินสายไฟ 12V ไปจนถึงการออกแบบระบบสำหรับฟาร์มจริง

> เปิดหน้านี้บนโทรศัพท์หรือแล็ปท็อปไว้ตลอดการอบรม ขั้นตอนทั้งหมดอยู่ที่นี่
> ส่วนที่ต้องเขียนด้วยมืออยู่ใน [ใบบันทึก](record-sheet.md) ซึ่งแจกเป็นกระดาษ

## อบรมแบ่งเป็นสามช่วง

| ช่วง | สิ่งที่ทีมจะทำได้เมื่อจบ |
|------|--------------------------|
| **[ช่วงที่ 1](session-1.md)** ระบบสมองกลฝังตัวในฟาร์ม: รับรู้ ตัดสินใจ สั่งการ | อ่านค่าเซนเซอร์บนแดชบอร์ด และสั่งปั๊มน้ำจากแล็ปท็อปและโทรศัพท์ |
| **[ช่วงที่ 2](session-2.md)** ตรรกะควบคุมอัตโนมัติและการออกแบบ Fail-safe สำหรับฟาร์ม | ระบบเปิดไฟเองเมื่อมืดโดยไม่กะพริบ รดน้ำเองเมื่ออากาศแห้ง และหยุดเองเมื่อน้ำหมดหรือเซนเซอร์หาย |
| **[ช่วงที่ 3](session-3.md)** โครงสร้างระบบ IoT: การสื่อสาร คลาวด์ แดชบอร์ด และการออกแบบระบบ | แดชบอร์ดสำหรับผู้ใช้จริง ดูจากนอกฟาร์มได้ โหนดที่เดินด้วยโซลาร์ และแบบร่างระบบของเราเอง |

แต่ละช่วงต่อยอดจากช่วงก่อนหน้า และใช้ชุดอุปกรณ์ชุดเดิมตลอด

## อุปกรณ์ที่ต้องใช้

**ของทีม**

- แล็ปท็อปของทีม ที่ติดตั้ง Home Assistant ไว้แล้วตามคู่มือที่ส่งให้ล่วงหน้า

**ในชุดอุปกรณ์**

- **บอร์ด GoGo-IoT** (คอนโทรลเลอร์ ESP32-C3) มีเซนเซอร์ในตัว: อุณหภูมิ ความชื้นอากาศ แสง ความกดอากาศ ความเร่ง พร้อมถ่าน 18650
- **สวิตช์ลูกลอย** พร้อมตัวแปลงหัว Grove และสาย Grove
- **บอร์ดรีเลย์** (ESP32-C6, รีเลย์ 1 ช่อง)
- **ปั๊มตู้ปลา 12V** พร้อมสายยาง, adapter 12V, แผงต่อสาย และสายไฟสำหรับต่อปั๊มผ่านรีเลย์
- **ตัวควบคุมการชาร์จ PWM 12V 10A** มีช่อง USB ทำหน้าที่กล่องจ่ายไฟ 12V ของทีม และ **แผงโซลาร์เซลล์ 12V 15W** สำหรับช่วงที่ 3
- สาย USB-A to USB-C, รางปลั๊กไฟ
- ภาชนะน้ำ 2 ใบ แก้วน้ำ 1 ใบ ถาดรอง ผ้าเช็ด (ผู้สอนจัดให้ที่โต๊ะ)
- บัตรประจำทีม (**สีโซนของทีม**, ชื่อและรหัส WiFi ของโซน, ชื่อผู้ใช้และรหัส Home Assistant)

> **ห้องแบ่งเป็นสามโซน แดง เขียว น้ำเงิน** แต่ละโซนมี WiFi ของตัวเอง บอร์ดในชุดอุปกรณ์ติดสีไว้และรู้จักเฉพาะ WiFi ของสีตัวเอง สีบนบอร์ด สีบนบัตร และ WiFi ที่แล็ปท็อปต่อ **ต้องเป็นสีเดียวกัน**

> **ชื่อบอร์ดไม่ได้อยู่บนบัตร** เราจะอ่านชื่อจากตัวบอร์ดเองผ่านสาย USB ในกิจกรรมที่ 1 เพราะบอร์ดแต่ละตัวตั้งชื่อตัวเองจากหมายเลขประจำเครื่อง ชื่อนั้นมีสีโซนอยู่ด้วย เช่น `gogo-iot-red-a1b2c3`

## บทบาทในทีม

ทีมมี 3–4 คน แต่มีแล็ปท็อปหลักเครื่องเดียว **สลับบทบาททุกครั้งที่เริ่มกิจกรรมใหม่**

| บทบาท | หน้าที่ |
|-------|---------|
| **Driver** | จับแล็ปท็อป ใช้งาน Home Assistant ตามขั้นตอน |
| **Hardware** | ดูแลบอร์ด สายไฟ ปั๊ม และน้ำ เป็นคนเดียวที่แตะอุปกรณ์บนถาด |
| **Recorder** | อ่านขั้นตอนให้ทีมฟัง และเขียนคำตอบลงใบบันทึก |

ถ้ามี 4 คน ให้คนที่ 4 เปิดแดชบอร์ดเดียวกันบนโทรศัพท์คู่ไปกับ Driver

ทุกกิจกรรมมี **คำถามของ Recorder** หนึ่งข้อ ที่ต้องเขียนคำตอบก่อนไปกิจกรรมถัดไป ไม่มีคะแนน แต่บังคับให้ทีมพูดกันว่าสิ่งที่เพิ่งทำหมายความว่าอะไร

## ข้อควรระวัง

- **น้ำอยู่ปลายโต๊ะด้านหนึ่ง แล็ปท็อปอยู่อีกด้าน** ปั๊มและภาชนะอยู่บนถาดรองเสมอ
- **แรงดันในห้องนี้คือ 12V** ซึ่งจับต้องได้ ระบบไฟบ้าน 220V ต้องให้ช่างไฟฟ้าติดตั้ง เราจะพูดถึงแต่จะไม่ต่อเอง
- เปิดปั๊มเฉพาะเมื่อปั๊มจุ่มอยู่ในน้ำ ปั๊มเดินแห้งนาน ๆ จะเสีย
- **แผงโซลาร์เซลล์ที่โดนแสงจ่ายไฟตลอดเวลา** ห้ามให้สายบวกและลบแตะกัน และต่อเข้าตัวควบคุมตามลำดับในใบงานเท่านั้น
- บอร์ดกับ Home Assistant คุยกันผ่าน **WiFi ของโซนเรา** (`farm-laptop-สี` สำหรับแล็ปท็อปและโทรศัพท์) ไม่ใช่ WiFi ทั่วไปของสถานที่ เราจะเปิดดูว่าคุยกันอย่างไรในช่วงที่ 3

## คำที่ใช้ซ้ำตลอดหลักสูตร

| คำ | ความหมายที่นี่ |
|----|----------------|
| **Input (เซนเซอร์)** | ส่วนที่รับรู้โลกจริงแล้วแปลงเป็นตัวเลข |
| **Logic (ตัวตัดสินใจ)** | ส่วนที่ดูค่าแล้วตัดสินใจ อาจเป็นสวิตช์กลไก คนหนึ่งคน หรือโปรแกรม |
| **Output (ตัวกระทำ / actuator)** | ส่วนที่ลงมือทำ เช่น ปั๊ม วาล์ว พัดลม |
| **Entity** | หนึ่งค่าหรือหนึ่งสิ่งที่ Home Assistant รู้จัก |
| **Automation** | กฎอัตโนมัติหนึ่งข้อ = trigger + condition + action |
| **Hysteresis** | ใช้ค่าเปิดกับค่าปิดต่างกัน เพื่อไม่ให้ Output เปิดปิดถี่ |
| **Fail-safe** | ออกแบบให้ระบบไปอยู่สถานะปลอดภัยเองเมื่อบางส่วนล้มเหลว |
| **Manual override** | สั่งหรือหยุด actuator ด้วยมือคน โดยไม่ผ่าน Logic |

เส้นทางเมนู Home Assistant ที่ใช้บ่อยรวมไว้ที่ [หน้าอ้างอิง](reference.md)
