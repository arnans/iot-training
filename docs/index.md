# IoT ในฟาร์มอัจฉริยะ

**ใบงานสำหรับผู้เข้าร่วม** · หลักสูตร "นวัตกรเกษตรอัจฉริยะ AIoT สำหรับเกษตรแม่นยำ" 

![ระบบที่เราจะสร้าง: บอร์ด GoGo-IoT พร้อมสวิตช์ลูกลอยในแก้วน้ำ บอร์ดรีเลย์ต่อปั๊มน้ำ 12V และแดชบอร์ด Home Assistant บนแล็ปท็อป](images/placeholder.png){ width="60%" }

ในการอบรมนี้ แต่ละกลุ่มจะได้ต่อวงจรและตั้งค่าระบบรดน้ำอัตโนมัติด้วยตัวเอง รวมถึงทดลองควบคุมไฟสวน โดยใช้ชุดอุปกรณ์เดิมตลอดทั้งสามช่วง เริ่มจากอ่านค่าเซนเซอร์ ต่อวงจรไฟฟ้า 12V (หลอดไฟก่อน แล้วจึงปั๊ม) และสร้างกฎควบคุม ก่อนนำสิ่งที่เรียนรู้ไปออกแบบระบบที่เหมาะกับฟาร์ม

> ใช้ใบงานบนเว็บนี้ดูขั้นตอนระหว่างทำกิจกรรม เปิดอ่านได้ทั้งบนโทรศัพท์และแล็ปท็อป
> ผลการทดลองและคำตอบกรอกลงช่องในใบงานได้เลย เบราว์เซอร์จะจำค่าไว้ในเครื่องที่กรอก และรวมทุกช่องไว้ใน[ใบบันทึกของกลุ่ม](record-sheet.md) ก่อนจบการอบรมกด **ดาวน์โหลดคำตอบ** ส่งไฟล์ให้ผู้สอน และ **พิมพ์ / บันทึก PDF** ไว้อ้างอิง
> ถ้ากรอกจากทั้งโทรศัพท์และแล็ปท็อป ให้ดาวน์โหลดจากเครื่องหนึ่งแล้ว **นำเข้าจากไฟล์** ที่อีกเครื่อง กลุ่มที่สะดวกเขียนกระดาษ พิมพ์ใบบันทึกตอนยังว่างได้

## การอบรมแบ่งเป็นสามช่วง

| ช่วง | สิ่งที่กลุ่มจะทำได้เมื่อจบ |
|------|--------------------------|
| **[ช่วงที่ 1](session-1.md)** ระบบสมองกลฝังตัวในฟาร์ม: รับรู้ ตัดสินใจ สั่งการ | อ่านค่าเซนเซอร์ ต่อวงจรหลอดไฟ 12V สั่งหลอดไฟจากแล็ปท็อปและโทรศัพท์ และมีกฎให้ไฟเปิด–ปิดเองตามแสง |
| **[ช่วงที่ 2](session-2.md)** ตรรกะควบคุมอัตโนมัติและการออกแบบ Fail-safe สำหรับฟาร์ม | ไฟสวนเปิด–ปิดเองโดยไม่กะพริบ ต่อปั๊มน้ำแล้วรดน้ำเองเมื่ออากาศแห้ง และหยุดเองเมื่อน้ำหมด เซนเซอร์ขาดการเชื่อมต่อ หรือสั่งแล้วปั๊มไม่เดินจริง |
| **[ช่วงที่ 3](session-3.md)** โครงสร้างระบบ IoT: การสื่อสาร คลาวด์ แดชบอร์ด และการออกแบบระบบ | อ่านกราฟข้อมูลของกลุ่มเอง แดชบอร์ดสำหรับผู้ใช้จริง เห็นวิธีดูฟาร์มจากนอกพื้นที่ และแบบร่างระบบของเราเองที่แลกเปลี่ยนกับอีกกลุ่มแล้ว |

แต่ละช่วงต่อยอดจากช่วงก่อนหน้า และใช้ชุดอุปกรณ์ชุดเดิมตลอด

## อุปกรณ์ที่ต้องใช้

**สิ่งที่กลุ่มต้องเตรียมมา**

- แล็ปท็อปของกลุ่ม ที่ติดตั้ง Home Assistant ไว้แล้วตาม[คู่มือเตรียมแล็ปท็อป](install.md)ที่ส่งให้ล่วงหน้า

**อุปกรณ์ที่ใช้ในการอบรม**

- **บอร์ด GoGo-IoT** (คอนโทรลเลอร์ ESP32-C3) มีเซนเซอร์ในตัว: อุณหภูมิ ความชื้นอากาศ แสง ความกดอากาศ ความเร่ง พร้อมถ่าน 18650
- **สวิตช์ลูกลอย** พร้อมตัวแปลงหัว Grove และสาย Grove
- **บอร์ดรีเลย์** (ESP32-C6, รีเลย์ 1 ช่อง)
- **หลอด LED 12V** แผงเลนส์สามดวง สายแดง (บวก) และสายดำ (ลบ) ใช้แทนหลอดไฟสวน เป็นอุปกรณ์ปลายทางตัวแรกที่ต่อในช่วงที่ 1
- **ปั๊มตู้ปลา 12V** ต่อแทนหลอดไฟในช่วงที่ 2 โดยเดินแห้ง ไม่ต่อน้ำ, อะแดปเตอร์ 12V, แผงต่อสาย และสายไฟสำหรับต่ออุปกรณ์ผ่านรีเลย์
- **charge controller PWM 12V 10A** มีช่อง USB ทำหน้าที่กล่องจ่ายไฟ 12V ของกลุ่ม และ **แผงโซลาร์เซลล์ 12V 15W** สำหรับดูประกอบในช่วงที่ 3 (ไม่ต้องต่อ)
- สาย USB-A to USB-C, รางปลั๊กไฟ
- แก้วน้ำ 1 ใบ สำหรับสวิตช์ลูกลอยในช่วงที่ 1 และ 2 (ผู้สอนจัดให้ที่โต๊ะ)
- บัตรประจำกลุ่ม (**สีโซนของกลุ่ม**, ชื่อและรหัส WiFi ของโซน) ส่วนชื่อผู้ใช้และรหัสผ่าน Home Assistant ผู้สอนจะแจ้งในกิจกรรมที่ 3

![ส่วนประกอบหลักของบอร์ด GoGo-IoT: ช่อง USB-C สวิตช์ ON/OFF ช่อง Grove 1 คอนโทรลเลอร์ ESP32-C3 ปุ่ม BOOT และกลุ่มเซนเซอร์ในตัว](images/gogo-iot-main-parts.png){ width="100%" }

> **แต่ละกลุ่มอยู่ในโซนสีแดง สีเขียว หรือสีน้ำเงิน** และใช้ WiFi ตามสีที่ระบุบนบัตรประจำกลุ่ม บอร์ดตั้งค่าให้เชื่อมต่อ WiFi ของโซนตนเองไว้แล้ว ก่อนเริ่มให้ตรวจว่า **สีบนบอร์ด สีบนบัตร และชื่อ WiFi ที่แล็ปท็อปเชื่อมต่อ ตรงกันทั้งหมด**

> **บัตรประจำกลุ่มไม่มีชื่อบอร์ด** ในกิจกรรมที่ 1 เราจะต่อสาย USB เพื่ออ่านชื่อจากบอร์ด แต่ละบอร์ดมีชื่อเฉพาะที่สร้างจากหมายเลขประจำเครื่องและระบุสีโซนไว้ด้วย เช่น `gogo-iot-red-a1b2c3`

## การทำงานในกลุ่ม

กลุ่มมี 4 คน แต่มีแล็ปท็อปหลักเครื่องเดียว ให้กลุ่มตกลงกันเองว่าใครทำอะไร โดยให้ทุกคนได้ลงมือทั้งบนหน้าจอและกับอุปกรณ์ ก่อนทดสอบแต่ละครั้ง ลองบอกกันในกลุ่มว่าคาดว่าจะเกิดอะไรขึ้น แล้วค่อยดูผล

ท้ายแต่ละกิจกรรมมีคำถามให้กลุ่มช่วยกันตอบ และกรอกคำตอบลงช่องท้ายคำถามก่อนเริ่มกิจกรรมถัดไป คำถามเหล่านี้ไม่มีคะแนน แต่ช่วยให้ทุกคนได้ทบทวนและอธิบายสิ่งที่เพิ่งทดลองร่วมกัน

## ข้อควรระวัง

- **แก้วน้ำของสวิตช์ลูกลอยอยู่ห่างจากบอร์ดและแล็ปท็อป** ในห้องนี้ปั๊มเดินแห้ง ไม่มีน้ำอื่นบนโต๊ะ
- **แรงดันในห้องนี้คือ 12V** ซึ่งจับต้องได้อย่างปลอดภัย ส่วนไฟบ้าน 220V ต้องให้ช่างไฟฟ้าเป็นคนติดตั้ง เราจะพูดถึงแต่ไม่ต่อเอง
- ปั๊มเดินแห้งได้ครั้งละไม่นาน ทดสอบเสร็จให้สั่ง Off ทันที ไม่ปล่อยให้เดินทิ้งไว้เกิน 1 นาที
- **แผงโซลาร์เซลล์ที่โดนแสงจ่ายไฟตลอดเวลา** ห้ามให้สายบวกและลบแตะกัน ในห้องอบรมเราไม่ต่อแผงเข้า charge controller เพราะชุดทดลองไม่มีแบตเตอรี่จริง
- บอร์ดกับ Home Assistant คุยกันผ่าน **WiFi ของโซนเรา** (`farm-laptop-สี` สำหรับแล็ปท็อปและโทรศัพท์) ไม่ใช่ WiFi ทั่วไปของสถานที่ เราจะเปิดดูว่าคุยกันอย่างไรในช่วงที่ 3

## คำที่จะเจอตลอดหลักสูตร

| คำ | ความหมาย |
|----|----------------|
| **Input (เซนเซอร์)** | ส่วนรับข้อมูลจากสิ่งที่ต้องการวัด เช่น เซนเซอร์วัดอุณหภูมิหรือสวิตช์ลูกลอย |
| **Logic (ตัวตัดสินใจ)** | ส่วนที่ใช้ข้อมูลมาตัดสินใจว่าจะสั่งงานอย่างไร อาจเป็นกลไก คน หรือโปรแกรม |
| **Output (อุปกรณ์ที่รับคำสั่งไปทำงาน / actuator)** | ส่วนที่ทำงานตามคำสั่ง เช่น ปั๊ม วาล์ว พัดลม |
| **Entity** | ค่าหรืออุปกรณ์หนึ่งรายการที่ Home Assistant รู้จัก เช่น ค่าอุณหภูมิหนึ่งค่า หรือสวิตช์หนึ่งตัว |
| **Automation** | กฎอัตโนมัติหนึ่งข้อ = trigger + condition + action |
| **Hysteresis** | การกำหนดเกณฑ์เปิดและปิดคนละค่า เพื่อไม่ให้อุปกรณ์เปิด–ปิดถี่เมื่อค่าที่วัดได้แกว่งใกล้เกณฑ์ |
| **Fail-safe** | การออกแบบให้ระบบหยุดหรือทำงานในลักษณะที่ปลอดภัยเมื่ออุปกรณ์หรือการควบคุมขัดข้อง |
| **Manual override** | การที่คนสั่งให้อุปกรณ์ทำงานหรือหยุดได้เอง โดยไม่รอคำสั่งอัตโนมัติ |

ดูเมนู Home Assistant ที่ใช้บ่อยและวิธีแก้ปัญหาได้ที่ [หน้าอ้างอิง](reference.md) และดูไฟล์ที่ต้องดาวน์โหลดกับลิงก์ทั้งหมดได้ที่ [รวมไฟล์และลิงก์](resources.md)
