# กิจกรรมที่ 6 — การอ่านข้อมูลที่บันทึกไว้ย้อนหลัง (History)

![เกษตรกรร่วมกันอ่านกราฟข้อมูลย้อนหลังบนแท็บเล็ตข้างแปลงผัก](images/activity-banners/activity-06-history.webp){ .activity-banner width="1600" height="267" loading="lazy" decoding="async" }

**20 นาที**

**อุปกรณ์ที่ใช้** แล็ปท็อป

เปิดข้อมูลที่เริ่มบันทึกไว้ตั้งแต่ช่วงที่ 2 ที่ผ่านมา หาว่าการเปลี่ยนแปลงบนกราฟตรงกับการทดลองใด แล้วคิดว่าถ้าเกิดในฟาร์มจริงควรตรวจอะไร

## ก่อนเริ่มช่วงที่ 3

ตรวจว่าระบบของกลุ่มกลับมาครบเหมือนตอนจบช่วงที่ 2 ก่อนเริ่มกิจกรรม

- [ ] Home Assistant ยังเปิดอยู่และเข้าใช้งานได้จากแล็ปท็อปของกลุ่ม หากเปิดไม่ได้ ให้อ่านหมายเลข IP จากหน้าจอเครื่อง VM อีกครั้ง
- [ ] บอร์ดทั้งสองออนไลน์ ค่าความชื้นอากาศและความสว่างอัปเดต และสั่งสวิตช์ของบอร์ดรีเลย์ได้
- [ ] **เปิดกฎ `รดน้ำ - เปิดปั๊ม` กลับเหมือนเดิม** เราปิดไว้ตอนพักเที่ยงเพื่อไม่ให้ปั๊มเดินแห้งโดยไม่มีคนดูแล และตรวจว่ากฎ fail-safe ทุกข้อเปิดอยู่
- [ ] ให้ `Pump Auto Mode` **ปิดไว้** ระหว่างทำกิจกรรมในช่วงนี้ เพื่อไม่ให้ปั๊มเริ่มเอง ส่วนกฎไฟสวนสองข้อกับกฎตั้งเวลาปิดไว้เหมือนเดิม

### 6.1 การเปิดกราฟดูข้อมูลย้อนหลัง { #a6-1 }


**เลือกข้อมูลและช่วงเวลา**

1. เปิด **History** จากเมนูด้านซ้าย
2. กด **Add target** แล้วเลือกความชื้นอากาศ แสง และ **สวิตช์ของบอร์ดรีเลย์**
3. เลือกช่วงเวลาตั้งแต่เริ่มช่วงที่ 2 จนถึงปัจจุบัน กราฟแสดงได้เฉพาะช่วงที่มีข้อมูลบันทึกไว้

> หากข้อมูลของกลุ่มมีน้อยจนเลือกเหตุการณ์มาอธิบายไม่ได้ ให้แจ้งผู้สอน แล้วใช้กราฟตัวอย่างที่ผู้สอนเปิดให้ดู หรือขอดูกราฟจากกลุ่มข้าง ๆ เมื่อบันทึกผล ให้ระบุในช่อง “ค่าหรือสถานะใดเปลี่ยน และเปลี่ยนอย่างไร” ว่าใช้กราฟของผู้สอนหรือของกลุ่มใด และสอบถามเจ้าของกราฟว่าตอนนั้นทดลองอะไร

### 6.2 เชื่อมกราฟกับการทดลอง { #a6-2 }

1. เลือกสามเหตุการณ์ในกราฟที่เชื่อมโยงกับการทดลองได้ เช่น แสงลดตอนครอบบอร์ด ความชื้นเพิ่มตอนเป่าลม หรือข้อมูลขาดตอนปิดบอร์ด บันทึกเหตุการณ์ เวลา การทดลองที่น่าจะเกี่ยวข้อง และสิ่งที่ควรตรวจหากพบในฟาร์มจริง หากยังไม่แน่ใจสาเหตุ ให้เขียนข้อสันนิษฐานและระบุว่า “ยังไม่แน่ใจ”

### 6.3 อ่านค่าต่ำสุด–สูงสุด { #a6-3 }

**อ่านและบันทึกค่าต่ำสุด–สูงสุด**

1. อ่านและกรอกค่าความชื้นอากาศในช่วงที่เลือก: ต่ำสุด {{n:s3.hist.hum_min|4}} % เวลา {{f:s3.hist.hum_min_t|5}} น. สูงสุด {{n:s3.hist.hum_max|4}} % เวลา {{f:s3.hist.hum_max_t|5}} น. ถ้ากราฟอ่านได้ไม่ละเอียด ให้ใช้ค่าโดยประมาณ

### 6.4 หาสาเหตุของข้อมูลที่ขาดหาย { #a6-4 }

**วิเคราะห์ช่องว่างของข้อมูล**

1. ลองสมมติว่าช่วงพักหลังช่วงที่ 1 บอร์ดยังมีไฟ แต่ Home Assistant ถูกปิดหรือนำออกจากห้อง เหตุใดจึงไม่มีข้อมูลช่วงนั้น {{f:s3.hist.why_gap|30}} หากนำระบบนี้ไปใช้ที่ฟาร์ม แล้วต้องการเก็บข้อมูลต่อเนื่อง เราต้องเปลี่ยนอะไรบ้าง {{f:s3.hist.farm_change|30}}

> ข้อนี้เป็นคำถามให้คิดจากการทำงานของระบบ ไม่ต้องหาช่วงพักดังกล่าวในกราฟที่เปิดอยู่ เพราะเราเลือกดูข้อมูลตั้งแต่เริ่มช่วงที่ 2
