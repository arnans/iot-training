# อ้างอิง: เมนู Home Assistant ที่ใช้บ่อย

ใช้หน้านี้ค้นหาเมนูและตรวจวิธีแก้ปัญหาระหว่างทำกิจกรรม

## เมนูที่ใช้บ่อย

| ต้องการ | ไปที่ |
|---------|-------|
| อ่านชื่อบอร์ด | เสียบ USB → [web.esphome.io](https://web.esphome.io) (Chrome/Edge) → Connect → Logs & Console → กด **Reset device** ในหน้าเว็บ (ไม่ใช่ปุ่มบนบอร์ด) → อ่านกรอบ DEVICE NAME |
| ติดตั้งเฟิร์มแวร์ลงบอร์ด (ช่วงที่ 4) | ดาวน์โหลดไฟล์ `.bin` ของโซนจาก[รวมไฟล์และลิงก์](resources.md) → เสียบ USB → [web.esphome.io](https://web.esphome.io) → Connect → **Install** → เลือกไฟล์ → รอจนสำเร็จ ไม่ต้องลบข้อมูล (Erase) |
| บอกบอร์ดตัวรับว่าฟังบอร์ดไหน (ช่วงที่ 4) | หน้าเว็บของตัวรับ (`http://` + IP) หรือหน้าอุปกรณ์ใน Home Assistant → ช่อง **ชื่อบอร์ดที่แปลง (sender name)** → พิมพ์รหัสหกตัวท้ายของบอร์ด GoGo-IoT |
| เพิ่มบอร์ด ESPHome | Settings → Devices & services → + Add integration → ESPHome → พิมพ์ **IP ของบอร์ด** ที่จดไว้ในช่อง Host, Port `6053` → Submit (ถ้าขึ้นรายการให้เลือก Setup another instance of ESPHome) → ตรวจช่อง **Device name** ในหน้า Name and assign ให้ตรงกับชื่อที่จดไว้ (ตัวพิมพ์เล็กหรือใหญ่ไม่ต้องสนใจ เช่น `Gogo-Iot-Red-6749A4` ตรงกับ `gogo-iot-red-6749a4`) → กดปุ่มมุมขวาล่าง (**Finish** หรือ **Skip and finish**) (บอร์ดไม่ขึ้นเป็นการ์ดเอง และใช้ชื่อ `.local` ไม่ได้) |
| ดู entity ของบอร์ด | Settings → Devices & services → ESPHome → กดชื่ออุปกรณ์ |
| ดูค่าจากบอร์ดโดยตรง ไม่ผ่าน Home Assistant | เบราว์เซอร์เปิด `http://` ตามด้วย IP ของบอร์ดที่จดไว้ (ใช้ชื่อบอร์ดแทน IP ไม่ได้) |
| แก้แดชบอร์ด | เปิดแดชบอร์ด → ไอคอนดินสอมุมบนขวา → + Add card → Done |
| สร้างแดชบอร์ดใหม่ | Settings → Dashboards → + Add dashboard → New dashboard from scratch |
| ดูกราฟย้อนหลัง | History → Add target → เลือกช่วงเวลา |
| ดูว่าใครสั่งอะไรเมื่อไร | Logbook |
| สร้าง automation | Settings → Automations & scenes → + Create automation → Create new automation |
| แก้หรือปิด automation | Settings → Automations & scenes → กดชื่อ (ใช้สวิตช์ด้านขวาเปิดหรือปิดการใช้งานกฎ) |
| ดูว่า automation ทำงานล่าสุดเมื่อไร | กดชื่อ automation → Last triggered หรือกด ⋮ → Traces |
| ดูข้อความแจ้งเตือน | ไอคอนกระดิ่งมุมล่างซ้าย |

## trigger, condition, action ที่ใช้ในหลักสูตร

กด **+ Add trigger**, **+ Add condition** หรือ **+ Add action** แล้วพิมพ์ชื่อ entity ในช่อง Search กดที่ entity แล้วเลือกรายการจากชื่อด้านล่าง

| ส่วน | ชื่อในรายการ | ใช้เมื่อ | ตัวอย่าง |
|------|-------------|---------|----------|
| Trigger | Illuminance crossed threshold · Relative humidity crossed threshold | ค่าตัวเลขข้ามเกณฑ์ (Threshold type: Below / Above) | แสง Below 200 · ความชื้นอากาศ Below 45 |
| Trigger | Moisture cleared / Moisture detected | สวิตช์ลูกลอยเปลี่ยนเป็น Dry / Wet | น้ำหมด |
| Trigger | Switch turned on / Switch turned off | รีเลย์เปลี่ยนสถานะ ใส่ **For at least** ถ้าต้องคงอยู่ครบเวลา | ปั๊ม On นาน 30 วินาที |
| Trigger | Time and sun → Time | ถึงเวลาที่กำหนด | At time 18:30 |
| Trigger | State changed (ช่อง **To**) | ต้องการจับ Unavailable / Unknown หรือ entity ที่ไม่มีรายการเฉพาะ | ความชื้นอากาศ To Unavailable, Unknown |
| Trigger | State (ช่อง **To** = Disconnected, **For** 30 วินาที) | ลิงก์ ESP-NOW จากแปลงเงียบไป (ช่วงที่ 4) | รับข้อมูลจากแปลง (link) To Disconnected |
| Condition | ช่อง **State** ในแผงด้านขวา (On / Off / Unavailable / Unknown) | entity ที่ไม่มีเงื่อนไขเฉพาะ | ปั๊มกำลังทำงาน เป็น Off |
| Condition | Moisture is detected / Moisture is not detected | ตรวจว่าลูกลอยเป็น Wet / Dry | รดน้ำได้เฉพาะเมื่อน้ำพอ |
| Condition | Illuminance · Relative humidity | ตรวจค่าตัวเลขตอนกฎเริ่ม | แสง Below 200 |
| Condition | Time and sun → Time | จำกัดช่วงเวลาที่กฎทำงาน | After 06:00 Before 18:00 |
| Action | Turn on switch / Turn off switch | สั่งรีเลย์ให้ทำงานหรือหยุด | สวิตช์ปั๊ม |
| Action | Send a persistent notification | แจ้งเตือนบนหน้าจอ Home Assistant | ปั๊มเดินเกินเวลา |

## รูปแบบการ์ดบนแดชบอร์ด

| การ์ด | ใช้แสดง |
|------|---------|
| **Gauge** | ค่าปัจจุบันหนึ่งค่า ตั้ง Severity ให้เปลี่ยนสีตามเกณฑ์ได้ |
| **History graph** | แนวโน้มย้อนหลัง ตั้งจำนวนชั่วโมงได้ |
| **Entities** | แสดงค่าหรือสวิตช์หลายรายการในการ์ดเดียว |
| **Tile** | ปุ่มใหญ่หนึ่งปุ่ม เหมาะกับการกดบนโทรศัพท์ |

## ตรวจสอบเมื่อใช้งานไม่ได้

![ส่วนประกอบหลักของบอร์ด GoGo-IoT: ช่อง USB-C สวิตช์ ON/OFF ช่อง Grove 1 คอนโทรลเลอร์ ESP32-C3 ปุ่ม BOOT และกลุ่มเซนเซอร์ในตัว](images/gogo-iot-main-parts.png){ width="100%" }

ตำแหน่งบนบอร์ด GoGo-IoT ที่ตารางข้างล่างอ้างถึง: สวิตช์ **ON / OFF** อยู่ใกล้ช่อง USB-C ส่วนปุ่ม **BOOT** เป็นคนละปุ่ม อยู่คนละฝั่งของบอร์ด และ**สวิตช์ลูกลอยต่อที่ช่อง Grove 1**

| อาการ | ตรวจตามลำดับ |
|-------|--------------|
| เพิ่มบอร์ดไม่สำเร็จ | **สีในชื่อบอร์ดตรงกับสีโซนของกลุ่มหรือไม่** · แล็ปท็อปอยู่บน `farm-laptop-สีเดียวกัน` หรือไม่ · ไฟบนบอร์ดติดหรือไม่ · IP ที่พิมพ์ตรงกับที่จดไว้หรือไม่ ไม่มี `http://` นำหน้า และ Port เป็น `6053` |
| หน้าต่าง log ใน [web.esphome.io](https://web.esphome.io) ว่างเปล่า | บอร์ดทำงานอยู่แล้วจึงไม่พิมพ์อะไรใหม่ กด **Reset device** ในหน้าเว็บ อย่าถอดสายหรือกดปุ่มบนบอร์ด |
| พิมพ์ IP แล้วต่อไม่ได้ หรือบอร์ดที่เคยเพิ่มแล้วกลายเป็น Unavailable | IP อาจเปลี่ยน เปิด [web.esphome.io](https://web.esphome.io) → Reset device → อ่านบรรทัด `IP ADDRESS` ที่ขึ้นหลังต่อ WiFi · ถ้าเลขเปลี่ยนจริง กด ⋮ ที่แถวบอร์ดใน Settings → Devices & services → ESPHome → **Reconfigure** แล้วพิมพ์ IP ใหม่ในช่อง Host (ชื่อและ entity เดิมยังอยู่) · ถ้า HA ปฏิเสธ แปลว่า IP นั้นเป็นบอร์ดอื่น (HA เช็กจาก MAC address ของบอร์ด) |
| entity เป็น unavailable | สวิตช์บนบอร์ด GoGo-IoT เปิดอยู่หรือไม่ (ในรอบจำลองปัญหามีคนปิดสวิตช์นี้) · บอร์ดยังเสียบไฟอยู่หรือไม่ · เราเตอร์ทำงานหรือไม่ · รอ 30 วินาทีให้บอร์ดต่อใหม่ |
| entity หายเป็นพัก ๆ หรือข้อมูลอัปเดตช้า | ดู entity `ความแรงสัญญาณ WiFi` ของบอร์ด หน่วย dBm เป็นเลขติดลบ **ยิ่งใกล้ 0 ยิ่งแรง** −50 ดีมาก · −65 พอใช้ · −75 อ่อน ค่าอาจหายเป็นพัก ๆ · −85 ใช้ไม่ได้ ลองขยับบอร์ดหรือแล็ปท็อปให้พ้นสิ่งกีดขวางโลหะ แล้วบอกผู้สอน |
| automation ไม่ทำงาน | สวิตช์ของกฎเปิดอยู่หรือไม่ · ค่า **ข้าม** เกณฑ์จริงหรือยัง · ดู Traces ว่าหยุดที่ condition ไหน |
| ไฟบนบอร์ดรีเลย์ไม่ติด | สาย USB ของบอร์ดเสียบช่อง USB ของ charge controller แน่นหรือไม่ · อะแดปเตอร์เสียบหรือยัง · จอ charge controller ติดหรือไม่ · ลองย้ายไปช่อง USB อีกช่อง หรือเสียบแล็ปท็อปดูว่าบอร์ดติดหรือไม่ (ถ้าติดแปลว่าช่อง USB ของ charge controller ไม่จ่ายไฟ ให้บอกผู้สอน) |
| ปั๊มไม่ทำงานแม้สวิตช์เป็น On | ดู entity `ปั๊มกำลังทำงาน (pump running)` ถ้าเป็น Off ทั้งที่สวิตช์ On แปลว่ารีเลย์ปิดวงจรแล้วแต่ปั๊มไม่สั่นจริง (หรือบอร์ด GoGo-IoT อยู่ไกลปั๊ม ให้ขยับเข้าใกล้ หรือเลือก `ความไวตรวจจับปั๊ม` เป็น สูง) · ไฟแสดงสถานะรีเลย์ติดหรือไม่ · สายเข้า COM และ NO แน่นหรือไม่ (ไม่ใช่ NC) · สายลบของปั๊มเข้าแถวลบหรือไม่ · ชุดทดลองนี้ใช้ปั๊มเดินแห้ง ไม่ต้องจุ่มน้ำ หากตรวจแล้วยังไม่ทำงาน ให้สั่ง Off และขอให้ผู้สอนช่วยตรวจ · จอ charge controller ติดแต่ขั้วโหลด 12V ไม่จ่ายไฟหรือไม่ (โหมดโหลดของ charge controller ให้บอกผู้สอน) |
| บอร์ดรีเลย์มีไฟแต่เชื่อมต่อเครือข่ายไม่ได้ | ดูไฟ **WiFi Status** บนบอร์ด ถ้า**กะพริบ** คือต่อ WiFi ไม่ได้ (ไฟอาจเริ่มกะพริบหลังการเชื่อมต่อขาดไปแล้วหลายวินาที) · สีในชื่อบอร์ดตรงกับสีโซนของกลุ่มหรือไม่ · หลังต่อไฟใหม่ รอถึงหนึ่งนาที · ย้ายปลายสาย USB จาก charge controller มาเสียบแล็ปท็อปเพื่ออ่าน log แล้วย้ายกลับ |
| หลอด LED ไม่ติดแม้รีเลย์คลิก | สายแดงของหลอดอยู่ที่ **NO** และสายดำอยู่แถวลบหรือไม่ · หลอด LED มีขั้ว ต่อกลับด้านจะไม่ติด (ไม่เสีย) สลับสายแล้วลองใหม่ · จอกล่องจ่ายไฟยังติดหรือไม่ |
| หลอดไฟติดหรือดับเองทั้งที่ไม่มีใครแตะ | กฎไฟสวน `มืด-เปิดไฟ` `สว่าง-ปิดไฟ` หรือกฎตั้งเวลา `ปิดไฟตามเวลา` ยังเปิดอยู่หรือไม่ (ดูสวิตช์ทางขวาใน Settings → Automations & scenes) · ถ้ารีเลย์ต่อกับปั๊มแล้ว กฎเหล่านี้ต้องปิดทุกข้อ |
| หลอดไฟ ไฟแสดงสถานะรีเลย์ หรือปั๊ม เปิดปิดถี่ | เกณฑ์ปิดยังเท่ากับเกณฑ์เปิดอยู่หรือไม่ (ต้องมี hysteresis) · หลอด LED ส่องเข้าเซนเซอร์แสงของบอร์ดเองหรือไม่ (หันหลอดออก) |
| ใช้มือครอบบอร์ดแล้วรีเลย์ไม่ตอบสนองทันที | รอให้ครบรอบส่งค่าของเซนเซอร์แสง (ดู update_interval ในไฟล์ตั้งค่า) · ค่าข้ามเกณฑ์จริงหรือแค่ใกล้ |
| โทรศัพท์เปิด Home Assistant ของแล็ปท็อปไม่ได้ | โทรศัพท์อยู่บน `farm-laptop-สีเดียวกับแล็ปท็อป` หรือไม่ (อินเทอร์เน็ตมือถือใช้ไม่ได้กับข้อนี้) · พิมพ์ **ที่อยู่ (IP) ที่จดไว้ในใบบันทึก** ไม่ใช่ localhost และไม่ใช่ `homeassistant.local` (ชื่อนี้ซ้ำกันทั้งห้อง อาจไปเจอเครื่องของกลุ่มอื่น) · ถ้าเลขที่จดไว้ใช้ไม่ได้ ให้อ่านที่อยู่จากหน้าจอ VM ใหม่ |
| บอร์ดตัวรับไม่ได้รับข้อมูลจากแปลง (ช่วงที่ 4) | รหัสในช่อง `ชื่อบอร์ดที่แปลง (sender name)` ตรงกับหกตัวท้ายของบอร์ด GoGo-IoT ของเราหรือไม่ · บอร์ด GoGo-IoT มีไฟและใช้เฟิร์มแวร์รุ่นใหม่หรือไม่ (หน้าเว็บของมันมี `แพ็กเก็ต ESP-NOW ที่ส่ง` และเพิ่มขึ้น) · **`ช่องสัญญาณ WiFi (channel)` ของสองบอร์ดเท่ากันหรือไม่** ถ้าไม่เท่า สองบอร์ดต่อเราเตอร์คนละตัว ปิดแล้วเปิดบอร์ดตัวรับใหม่ หรือย้ายให้ใกล้กัน แล้วดูช่องอีกครั้ง · `บอร์ดอื่นที่ได้ยิน` เปลี่ยนอยู่หรือไม่ ถ้าเปลี่ยน ตัวรับทำงานปกติ ปัญหาอยู่ที่รหัสหรือช่องสัญญาณ · ดู log ของตัวรับที่ web.esphome.io บรรทัด `<<< GOGO,` |
| ติดตั้งเฟิร์มแวร์ที่ web.esphome.io ไม่สำเร็จ (ช่วงที่ 4) | ใช้ Chrome หรือ Edge · ปิดแท็บ web.esphome.io อื่นและหน้าต่าง log ที่ค้างอยู่ก่อน · ลองสาย USB เส้นอื่น · กดปุ่ม **BOOT** บนบอร์ดค้างไว้ขณะเสียบสาย แล้ว Connect ใหม่ · ถ้าสำเร็จแต่บอร์ดหายจาก Home Assistant ดูสีในชื่อไฟล์ที่ติดตั้ง |
| จอ charge controller ไม่ติด | ต่ออะแดปเตอร์เข้าคู่ขั้วแบตเตอรี่ (คู่กลาง) หรือไม่ · ต่อขั้วบวกและขั้วลบถูกต้องหรือไม่ · อะแดปเตอร์เสียบปลั๊กหรือยัง |
