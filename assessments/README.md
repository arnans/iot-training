# แบบทดสอบรายบุคคลก่อน–หลังเรียน

แบบทดสอบภาษาไทยสำหรับหลักสูตร IoT ในฟาร์ม รวม **6 ชุด 45 ข้อ** จัดทำตามใบงานช่วงที่ 1–3

## ไฟล์ Aiken สำหรับนำเข้า LMS

แบบทดสอบทั้ง 6 ชุดผ่านการปรับภาษาไทย และเป็นแบบเลือกตอบทั้งหมด ข้อคำตอบสั้นเดิม 9 ข้อปรับเป็นแบบเลือกตอบโดยคงประเด็นที่วัดและรหัสข้อเดิม ไฟล์ `.txt` ใช้รูปแบบ Aiken และบันทึกเป็น UTF-8

| ช่วง | ก่อนเรียน | หลังเรียน | เนื้อหาหลัก |
|---|---|---|---|
| 1 | [5 ข้อ — Aiken](session-1-pre.txt) | [10 ข้อ — Aiken](session-1-post.txt) | Input / Logic / Output เซนเซอร์ รีเลย์ และการเลือกอุปกรณ์ |
| 2 | [5 ข้อ — Aiken](session-2-pre.txt) | [10 ข้อ — Aiken](session-2-post.txt) | Trigger / Condition การแยกเกณฑ์เปิด–ปิด และการป้องกันเมื่อระบบขัดข้อง |
| 3 | [5 ข้อ — Aiken](session-3-pre.txt) | [10 ข้อ — Aiken](session-3-post.txt) | เครือข่ายภายใน การเข้าถึงจากภายนอก ข้อมูลย้อนหลัง แดชบอร์ด และพลังงาน |

- ก่อนเรียนแต่ละชุด: เลือกตอบ 5 ข้อ รวม 5 คะแนน
- หลังเรียนแต่ละชุด: เลือกตอบ 10 ข้อ รวม 10 คะแนน
- ทุกข้อมี 4 ตัวเลือก ถูกเพียงข้อเดียว ข้อที่เปลี่ยนจากคำตอบสั้นอาจมีความยากต่างจากเดิม เพราะผู้เรียนเห็นตัวเลือกแล้ว
- ข้อสอบฉบับปรับปรุงเน้นทำนายสถานะตามลำดับเหตุการณ์ วินิจฉัยจากหลักฐาน และเลือกวิธีแก้ที่ตรงกับเงื่อนไข ตัวลวงสะท้อนความเข้าใจคลาดเคลื่อน เช่น คิดว่า condition สั่งหยุดงานที่เริ่มไปแล้ว หรือสถานะ On ยืนยันว่าปั๊มเดินจริง
- เฉลยแต่ละข้อระบุสิ่งที่วัด ข้อก่อนเรียนใช้ตรวจแนวคิดตั้งต้น จึงไม่จำเป็นต้องตอบได้ทุกข้อก่อนอบรม ความสามารถแยกผู้ที่เข้าใจกับผู้ที่เดายังต้องตรวจจากผลทดลองใช้ข้อสอบจริง
- แนะนำให้ทำก่อนและหลังแต่ละช่วงเป็นรายบุคคล ใช้เวลา 5–7 นาทีและ 15 นาทีตามลำดับ
- ยังไม่ได้กำหนดคะแนนผ่านหรือจำนวนครั้งที่ทำได้ ผู้จัดสามารถกำหนดใน LMS ตามนโยบายการอบรม

## การนำเข้า LMS

ใช้ไฟล์ `.txt` กับ LMS ที่รองรับ Aiken เช่น Moodle โดยเลือกชนิดไฟล์นำเข้าเป็น **Aiken** ไม่ใช้ไฟล์ Markdown ในขั้นตอนนำเข้า

1. สร้างแบบทดสอบ 6 ชุดตามชื่อไฟล์ แยกก่อนเรียนและหลังเรียนของแต่ละช่วง
2. นำเข้าไฟล์ Aiken ของแต่ละชุด แล้วตรวจจำนวนข้อ: ก่อนเรียน 5 ข้อ หลังเรียน 10 ข้อ
3. ตั้งเป็นแบบเลือกคำตอบเดียว ข้อละ 1 คะแนน ผิดหรือไม่ตอบได้ 0 และตรวจคะแนนรวมของแต่ละชุด
4. ตั้งเวลาแสดงเฉลยตามแผนการวัดผล แนะนำให้เปิดหลังปิดแบบทดสอบหลังเรียน
5. ทดลองตอบถูก ตอบผิด และเว้นว่าง ตรวจคะแนน การแสดงภาษาไทย และสัญลักษณ์ก่อนเปิดให้ผู้เรียนใช้จริง

ตรวจรูปแบบ Aiken และความตรงกันของต้นฉบับกับเฉลยด้วยสคริปต์แล้ว แต่ยังไม่ได้ทดลองนำเข้าระบบ LMS ปลายทาง

## การแก้ไขและสร้างไฟล์ใหม่

แก้คำถาม ตัวเลือก และเฉลยในไฟล์ `session-*.md` จากนั้นรันจากโฟลเดอร์หลักของโครงการ:

```sh
node scripts/export_assessments.cjs
node scripts/export_assessments.cjs --check
```

คำสั่งแรกสร้างไฟล์ Aiken ทั้ง 6 ชุดและ `answer-key.md` ให้ตรงกับต้นฉบับ คำสั่งที่สองตรวจจำนวนข้อ รหัสข้อ ตัวเลือก เฉลย รูปแบบ Aiken และความตรงกันของไฟล์ โดยไม่แก้ไขไฟล์

ถ้าเก็บไฟล์ใน Git repository ที่เปิดสาธารณะ เฉลยก็เป็นสาธารณะเช่นกัน การซ่อนเฉลยใน LMS ไม่ได้ทำให้ไฟล์ใน repository เป็นความลับ
